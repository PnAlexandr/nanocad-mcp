nanoCAD MCP 0.5.0
=================

Подключает открытый чертёж nanoCAD к настольному Codex, ChatGPT для Windows, Claude Desktop
и другим программам с поддержкой локального MCP (STDIO).

Установка
---------
1. Под своей обычной учётной записью Windows установите и откройте Codex
   и войдите в свой аккаунт ChatGPT. Если nanoCAD 24, 25 или 26 установлен
   впервые, откройте и закройте его один раз, чтобы он создал профиль.
2. Закройте nanoCAD, распакуйте весь архив и запустите install.bat.
   Для загрузки Python и библиотек нужен интернет. Установщик регистрирует
   nanocad-mcp в Codex этого пользователя. При наличии закрытого Claude
   Desktop настроит и его. Для подключения только к одному клиенту можно
   запустить install.bat -Client Codex или install.bat -Client Claude.
3. После строки «Codex подтвердил регистрацию сервера nanocad-mcp»
   перезапустите Codex. Откройте чертёж в nanoCAD и нажмите «Вкл / Выкл»
   на вкладке MCP или кнопку питания на панели «nanoCAD MCP».
4. В новом чате Codex напишите «Вызови status сервера nanocad-mcp
   и скажи, какой чертёж открыт». Сверьте имя DWG с заголовком окна.

Файлы устанавливаются в %LOCALAPPDATA%\nanoCAD-MCP. Регистрация относится
к запустившему установщик пользователю Windows. Каждый коллега выполняет
эти шаги под своей учётной записью. Для обновления повторите install.bat.

Включение и выключение
----------------------
При каждом запуске nanoCAD доступ выключен. Нажатие на кнопку переключает
доступ для всех клиентов. В командной строке nanoCAD появится сообщение
«nanoCAD MCP: ON» или «nanoCAD MCP: OFF». Эту же кнопку можно вызвать
командой NanoCADMCPToggle. Закрытие nanoCAD выключает доступ.

Доступ получает только тот экземпляр nanoCAD, в котором нажали кнопку.
Если открыто несколько экземпляров, включение в другом переключает доступ
на него. Уже запущенная операция может завершиться. После включения
переподключать сервер в чате не требуется.

Ручное подключение в ChatGPT для Windows
---------------------------------------
1. В приложении ChatGPT откройте «Настройки» → «MCP servers» → «Add server».
2. Имя — nanoCAD. Тип — STDIO.
3. Откройте ярлык «nanoCAD MCP» на рабочем столе и скопируйте из окна
   значения «Команда» и «Аргумент».
   Команда — полный путь к python.exe. Добавьте путь к nanocad_mcp.py
   как один аргумент. Сохраните настройку и нажмите «Restart».
4. Включите доступ кнопкой внутри nanoCAD и напишите в чате, например:
   «Вызови инструмент status сервера nanoCAD и скажи, какой чертёж открыт».

Для подключения нужен доступ к локальным MCP в вашем приложении.
Справка ChatGPT — https://learn.chatgpt.com/docs/extend/mcp

Claude Desktop и другие клиенты
------------------------------
Для Claude полностью закройте приложение через значок у часов и запустите
снова. Если вы уже подключали старую версию в другом клиенте, обновите пути
в его настройках по полям «Команда» и «Аргумент». Используйте эти же поля
в любом клиенте с поддержкой локального MCP (STDIO). Клиент и nanoCAD
должны работать в одном сеансе Windows.

Для ChatGPT в браузере потребуется отдельное подключение через удалённый MCP.
OpenAI Secure MCP Tunnel поддерживает локальный STDIO. Настройка туннеля
выполняется отдельно. Справка — https://developers.openai.com/api/docs/guides/secure-mcp-tunnels

Что попробовать
---------------
• «Прочитай выделенное» (get_selection, nanoCAD 26). Выделите объекты мышью.
  Для отрезков ответ включает координаты концов в мировой системе и длину в 3D,
  для блоков — имя, точку вставки и атрибуты. За один запрос выводится до 500 объектов.
• «Измерь выделенное» (measure_selection, nanoCAD 26). Измеряет всё выделение,
  суммирует длины кривых и площади замкнутых плоских кривых и штриховок.
  Ответ содержит единицы чертежа, число измеренных объектов, пропуски и ошибки.
  Для площади используются квадратные единицы. Контуры измеряются по отдельности.
  При первом вызове сервер загружает комплектную NanoCadMcp.Tools26.dll в разрешённый
  экземпляр nanoCAD. Для установки на рабочее место достаточно архива, SDK не требуется.
• «Проверь подложку и перечисли проблемы, без изменений».
• «Посчитай длину полилиний на слое ОВ_Отопление».
• «Выведи тексты или атрибуты блоков из чертежа».

Сервер умеет также изменять и сохранять чертёж и выполнять код через nanoCAD.
Для массовых правок сначала попросите показать план. Инструмент backup
копирует последнюю сохранённую версию DWG рядом с исходным файлом.

Если возникла ошибка
--------------------
• «Доступ выключен» — нажмите кнопку «Вкл / Выкл» внутри nanoCAD.
• Панель скрыта — в классическом интерфейсе щёлкните правой кнопкой рядом
  с инструментальными панелями и включите «nanoCAD MCP» в списке.
• Вкладка скрыта — щёлкните правой кнопкой на верхней ленте и включите MCP
  в списке вкладок. После установки перезапустите nanoCAD.
• Кнопка не запускает LISP — проверьте, разрешена ли загрузка скриптов из
  %LOCALAPPDATA%\nanoCAD-MCP в настройках вашей организации.
• «nanoCAD не найден» — запустите его без повышения прав и откройте DWG.
• «nanoCAD занят» — завершите текущую команду или закройте диалог.
• «Другой MCP-клиент работает с nanoCAD» — дождитесь завершения его операции.
• nanoCAD закрылся с ошибкой при нажатии кнопки — отправьте тому, кто передал
  файлы, %LOCALAPPDATA%\nanoCAD-MCP\toggle.log. Последняя строка показывает
  шаг, на котором всё остановилось.

Исходный сервер 0.2.1 проверялся автором на nanoCAD СПДС 24. В версии 0.4.3
кнопка больше не вызывает COM внутри nanoCAD: она запускает помощника функцией
startapp, а тот находит nanoCAD по родительским процессам. Эта версия кнопки
проверена только на симуляции. Её работу и подключение к реальному чертежу
на nanoCAD 24–26 нужно проверить на установленной версии.
