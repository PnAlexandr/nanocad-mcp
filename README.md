# nanoCAD MCP

Локальный MCP-сервер для Windows. Подключает открытый чертёж nanoCAD к Codex и другим клиентам MCP через STDIO. Доступ включается кнопкой **«Вкл / Выкл»** в том экземпляре nanoCAD, с которым вы хотите работать.

## Версия 0.7.9

В nanoCAD 26 доступны четыре команды для профильных модулей.

| Запрос в чате | Команда MCP |
|---|---|
| Открой менеджер проекта Электро | `electro_project_manager` |
| Открой страницу свойств объекта Электро | `electro_object_properties` |
| Поставь уклоноуказатель между опорными точками | `geonics_slope_marker` |
| Посмотри, что видно по оврагу на выделенном участке | `geonics_inspect_relief` с дескрипторами из `get_selection` |

Первые три команды проверяют наличие штатной команды в разрешённом окне. После предварительного просмотра клиент передаёт путь `document` из ответа и `dry_run=false`. Ответ `queued` означает передачу команды в nanoCAD. Для уклоноуказателя выберите в модели две опорные точки GeoniCS и завершите диалог. Проверить результат можно по числу объектов `GCDBGRADEMARKER` и свойствам нового объекта.

Для постановки уклоноуказателя нужен проект GeoniCS. При первом запуске GeoniCS может предложить открыть или создать его. В версии 26 предварительная проверка также учитывает загруженный модуль GcSrfEngine, который обслуживает эту команду.

В пробной сборке 0.7.9 на копии DWG проверены чтение двух опорных точек и запуск команды до выбора точек. В тестовом проекте без назначенной проектной поверхности GeoniCS отклонил выбор. Проверка создания уклоноуказателя в проекте с подключённой поверхностью остаётся открытой.

Осмотр рельефа возвращает объекты модели, слои и явные упоминания оврага, бровок и тальвега. Без списка объектов команда читает всю модель. При обновлении с сохранённым индивидуальным набором включите нужные команды в группах «Электро» и «GeoniCS · вертикальная планировка».

В nanoCAD 26, СПДС и Электро кнопка регистрирует COM-объект своего процесса. Когда открыто несколько программ, нажмите кнопку в нужной. В ответе `status` видны имя чертежа и `process_id`. Переключение проверено на двух одновременно открытых приложениях и копии DWG в Электро. Для 24 и 25 сохранён прежний способ подключения.

В новом профиле включены 27 базовых команд. На вкладке **MCP** и на панели инструментов расположены три кнопки.

| Кнопка | Действие |
|---|---|
| **Вкл / Выкл** | Даёт доступ к окну, где вы нажали кнопку. Повторное нажатие в этом окне выключает доступ. |
| **Доп.** | Переключает набор из 109 команд, включая 2D-геометрию, размеры, блоки, слои и измерения. |
| **3D** | Переключает 44 команды для тел, поверхностей, сетей и других 3D-операций. Также доступна через ярлык **nanoCAD MCP 3D** на рабочем столе. |

Первое включение активирует весь набор. Если вы выбрали отдельные команды, после выключения и повторного включения восстановится ваш выбор. Для точной настройки откройте ярлык **nanoCAD MCP**, отметьте нужные команды и нажмите **Применить**. Настройки общие для пользователя Windows. Если клиент хранит список команд в кэше, переподключите сервер. Все наборы бесплатны.

## Установка

1. Запустите nanoCAD хотя бы один раз, затем закройте перед установкой.
2. Распакуйте архив 0.7.9 и запустите `nanocad-mcp\install.bat` под своей учётной записью. Для установки нужен интернет. [Скачать установщик 0.7.9](https://github.com/PnAlexandr/nanocad-mcp/releases/download/v0.7.9/nanoCAD-MCP-Codex-0.7.9.zip)
3. Перезапустите MCP-клиент, откройте DWG и нажмите **MCP → Вкл / Выкл**. Проверьте имя чертежа через `status`.

## Что попробовать в nanoCAD 26

| Запрос | Результат |
|---|---|
| «Прочитай выделенное» — `get_selection` | Для отрезка возвращает слой, дескриптор, координаты концов и длину в 3D. Для вставки блока возвращает имя, точку вставки и атрибуты. |
| «Измерь выделенное» — `measure_selection` | Складывает длины выбранных кривых и площади замкнутых плоских контуров и штриховок. Ответ содержит единицы чертежа, число измеренных объектов, пропуски и ошибки. |

Обе команды читают текущее выделение. При первом вызове сервер загружает комплектную DLL в подключённый nanoCAD 26. Проверено в СПДС 26 на трёх выделенных отрезках, а также на дуге, окружности, прямоугольнике и пустом выделении.

## Сборка DLL для разработчиков

Исходники модуля находятся в [src/NanoCadSelection](src/NanoCadSelection). Понадобятся Windows x64, .NET SDK 6 и библиотеки платформы nanoCAD 26. Для версии 0.5.0 использовался SDK платформы 26.0.7714.4962.

В PowerShell из корня репозитория укажите свой путь к распакованному SDK и выполните:

```powershell
$env:NCadSDK = 'C:\SDK\nanoCAD26'
Push-Location src\NanoCadSelection
try {
    dotnet build -c Release -p:BuildMcpServerModule=true
    if ($LASTEXITCODE -ne 0) { throw 'Сборка DLL завершилась с ошибкой' }
    Copy-Item bin\Release\net6.0-windows\NanoCadMcp.Tools26.dll ..\..\nanocad-mcp\
} finally {
    Pop-Location
}
```

Модули окна и дополнительных команд собираются из того же каталога командами `dotnet build ../NanoCadWindow -c Release` и `dotnet build ../NanoCadExtras -c Release`. Для Extras также нужна M3D из установленной платформы nanoCAD. Скопируйте собранные `NanoCadMcp.Window26.dll` и `NanoCadMcp.Extras26.dll` в каталог установщика.

Команда сервера для MCP-клиента — Python из окружения установки. Аргумент — путь к `nanocad_mcp.py`. Установщик настраивает это подключение для текущего пользователя. В комплекте есть инструменты изменения чертежей и выполнения кода через nanoCAD, поэтому включайте доступ для доверенного клиента.
