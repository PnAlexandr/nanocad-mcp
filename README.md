# nanoCAD MCP

Локальный MCP-сервер для Windows. Подключает открытый чертёж nanoCAD к Codex и другим клиентам MCP через STDIO. Доступ включается кнопкой **«Вкл / Выкл»** в том экземпляре nanoCAD, с которым вы хотите работать.

## Установка 0.5.0

1. Запустите nanoCAD хотя бы один раз, затем закройте его перед установкой.
2. Скачайте и распакуйте [готовый установщик 0.5.0](https://github.com/PnAlexandr/nanocad-mcp/releases/download/v0.5.0/nanoCAD-MCP-Codex-0.5.0.zip).
3. Запустите `nanocad-mcp\install.bat` под своей учётной записью Windows. Для первой установки нужен интернет. DLL входит в архив, SDK пользователю устанавливать не требуется.
4. Перезапустите Codex, откройте чертёж и нажмите **MCP → Вкл / Выкл** в nanoCAD. Попросите Codex вызвать `status` и проверьте имя открытого чертежа и версию сервера.

Инструкции для других клиентов и параметры ручного подключения приведены в [руководстве по установке](nanocad-mcp/README.txt).

## Что попробовать в nanoCAD 26

| Запрос | Результат |
|---|---|
| «Прочитай выделенное» — `get_selection` | Для отрезка возвращает слой, дескриптор, координаты концов и длину в 3D. Для вставки блока возвращает имя, точку вставки и атрибуты. |
| «Измерь выделенное» — `measure_selection` | Складывает длины выбранных кривых и площади замкнутых плоских контуров и штриховок. Ответ содержит единицы чертежа, число измеренных объектов, пропуски и ошибки. |

Обе команды читают текущее выделение. При первом вызове сервер загружает комплектную DLL в подключённый nanoCAD 26. Проверено в СПДС 26 на трёх выделенных отрезках, а также на дуге, окружности, прямоугольнике и пустом выделении.

## Сборка DLL для разработчиков

Исходники модуля находятся в [src/NanoCadSelection](src/NanoCadSelection). Понадобятся Windows x64, .NET SDK 6 и библиотеки платформы nanoCAD 26. Для версии 0.5.0 использовался SDK платформы 26.0.7714.4962.

В PowerShell из корня репозитория укажите свой путь к распакованному SDK и выполните:

```powershell
$env:NCadSDK = 'C:\SDK\nanoCAD26'
Push-Location src\NanoCadSelection
try {
    dotnet build -c Release -p:BuildMcpServerModule=true
    if ($LASTEXITCODE -ne 0) { throw 'Сборка DLL завершилась с ошибкой' }
    Copy-Item bin\Release\net6.0-windows\NanoCadMcp.Tools26.dll ..\..\nanocad-mcp\
} finally {
    Pop-Location
}
```

Команда сервера для MCP-клиента — Python из окружения установки. Аргумент — путь к `nanocad_mcp.py`. Установщик настраивает это подключение для текущего пользователя. В комплекте есть инструменты изменения чертежей и выполнения кода через nanoCAD, поэтому включайте доступ для доверенного клиента.
